## 4. 画面遷移図用の構造データ

```
[未ログイン]
  ↓
/ (ホーム - 未ログイン)
  ├─ /login (ログインボタン)
  └─ /register (新規登録ボタン)

/register (新規登録)
  ├─ /login (登録成功後、自動遷移)
  └─ /login (既にアカウントをお持ちの方は、リンク)

/login (ログイン)
  ├─ / (ログイン成功後、自動遷移)
  └─ /register (アカウントをお持ちでない方は、リンク)

[ログイン済み]
  ↓
/ (ホーム - ログイン済み)
  ├─ /study/today (今日の復習ボタン、タスクがある場合のみ)
  ├─ /books (新規ログを書くボタン)
  ├─ /study/today (ヘッダー: 今日の復習)
  ├─ /books (ヘッダー: 教材管理)
  ├─ /reviews (ヘッダー: レビュー)
  ├─ /notifications (ヘッダー: 通知)
  ├─ /revenue-shares (ヘッダー: 収益還元)
  ├─ /gifts (ヘッダー: ギフト)
  └─ [フローティングメニュー]
      ├─ / (ホーム)
      ├─ /study/today (今日の復習)
```

## 補足情報

### 認証状態の確認
- 未ログイン状態で認証必須ページにアクセスした場合、自動的に `/login` にリダイレクトされる
- ログイン成功後、認証トークンはCookie（`token`）に保存される
- 各API呼び出し時にCookieが自動的に送信される

### エラーハンドリング
- 各フォーム送信時にエラーが発生した場合、エラーメッセージが画面に表示される
- ネットワークエラーの場合、適切なエラーメッセージが表示される

### データの永続化
- 書籍登録、ステータス更新、削除などの操作は即座に画面に反映される
- ページリロード時も、データはサーバーから取得され、最新状態が表示される
