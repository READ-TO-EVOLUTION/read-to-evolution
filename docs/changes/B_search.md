## 技術的詳細

### 検索対象

- **Reviewモデル**
  - `searchKeywords`: 検索ワードフィールド（部分一致）
  - `comment`: コメントフィールド（部分一致）

### 検索方式

- **Prisma `contains`**を使用
- SQLite対応（大文字小文字区別なし、部分一致）
- `OR`条件で`searchKeywords`または`comment`に部分一致

### 認証

- **認証必須**: `requireAuth`を使用（自分のレビューのみ検索）

### API仕様

- **エンドポイント**: `GET /api/reviews?q=...`
- **パラメータ**:
  - `q` (オプション): 検索クエリ（文字列）
- **返却**: 既存の`GET /api/reviews`と同じ形式（`{ reviews: [...] }`）

## 動作確認手順

### 前提条件

1. 開発サーバーが起動している（`npm run dev`）
2. ログインしている（レビューページを表示するため）
3. レビューが少なくとも1件存在する（検索テスト用）

### 確認手順

1. **レビューページを開く**
   - URL: `http://localhost:3001/reviews`（または`http://localhost:3000/reviews`）
   - ブラウザでアクセス

2. **検索ボックスが表示されることを確認**
   - ページ上部に検索ボックス、検索ボタンが表示される
   - 検索クエリが入力されていない場合は、クリアボタンは表示されない

3. **検索機能の動作確認**
   - 検索ボックスにキーワードを入力（例: "技術"）
   - 「検索」ボタンをクリック
   - `searchKeywords`または`comment`に該当キーワードが含まれるレビューのみが表示される

4. **検索クリア機能の動作確認**
   - 検索クエリを入力した状態で「クリア」ボタンをクリック
   - 検索クエリがクリアされ、全レビューが表示される

5. **APIの動作確認**
   - ブラウザの開発者ツール（F12）を開く
   - Networkタブで`/api/reviews?q=...`のリクエストを確認
     - ステータスコードが200であること
     - レスポンスに`reviews`配列が含まれること
     - 検索結果が正しくフィルタリングされていること

### 失敗時の確認ポイント

1. **検索結果が表示されない**
   - 原因: 検索クエリに該当するレビューが存在しない
   - 確認: データベースで`reviews`テーブルの`search_keywords`または`comment`フィールドを確認
   - 確認: 検索クエリが正しくエンコードされているか確認（`encodeURIComponent`）

2. **「レビュー一覧の取得に失敗しました」が表示される**
   - 原因: APIエラー（500エラーなど）
   - 確認: サーバーのターミナルログを確認
   - 確認: `app/api/reviews/route.ts`のエラーハンドリングを確認

3. **検索ボタンを押しても検索が実行されない**
   - 原因: フォーム送信イベントの処理ミス
   - 確認: ブラウザの開発者ツール（F12）のConsoleタブでエラーメッセージを確認
   - 確認: `handleSearch`関数が正しく呼び出されているか確認

4. **検索結果が正しくフィルタリングされない**
   - 原因: Prisma `contains`の動作確認
   - 確認: SQLiteの`LIKE`演算子の動作を確認（大文字小文字区別なし）
   - 確認: `searchKeywords`と`comment`の両方で検索されているか確認（`OR`条件）
