## 技術的詳細

### 使用API

- **`GET /api/reviews/public?bookId=...&limit=...&offset=0`**
  - 根拠: `app/api/reviews/public/route.ts:1-112`
  - 認証: 不要（未ログインでも閲覧可能）
  - 返却項目: `reviews`配列、`pagination`情報
  - 並び順: `createdAt: 'desc'`（新しい順）

### 表示条件

- **表示対象**: `isPublic: true`のレビューのみ
- **絞り込み**: `bookId`で絞り込み（APIパラメータで指定）
- **取得件数**: デフォルト5件（`limit={5}`）
- **個人情報**: `user.name`のみ表示（`user.email`はレスポンスに含まれない）

### 表示位置

- **ページ**: 本棚一覧ページ（`/books`）
- **位置**: 各書籍カード内、`ReviewSummaryCard`の下
- **表示条件**: すべての書籍カードに表示（タブ・フィルタに依存しない）

## 動作確認手順

### 前提条件

1. 開発サーバーが起動している（`npm run dev`）
2. ログインしている（本棚一覧ページを表示するため）
3. 本棚に少なくとも1冊の書籍が登録されている
4. 対象書籍に公開レビュー（`isPublic: true`）が存在する

### 確認手順

1. **本棚一覧ページを開く**
   - URL: `http://localhost:3001/books`（または`http://localhost:3000/books`）
   - ブラウザでアクセス

2. **公開レビューが表示されることを確認**
   - 各書籍カードに「みんなのレビュー (X件)」セクションが表示される
   - 公開レビューが存在する書籍では、レビュー一覧が表示される
   - 公開レビューが存在しない書籍では、「まだ公開レビューがありません」と表示される

3. **表示内容の確認**
   - ユーザー名が表示される
   - 評価（★）が表示される
   - コメントが表示される（存在する場合）
   - お気に入りフレーズが表示される（存在する場合）
   - 感情タグが表示される
   - ネタバレフラグが表示される（`hasSpoiler: true`の場合）
   - 作成日が表示される

4. **エラー時の確認**
   - ブラウザの開発者ツール（F12）を開く
   - Consoleタブでエラーメッセージを確認
   - Networkタブで`/api/reviews/public`のリクエストを確認
     - ステータスコードが200であること
     - レスポンスに`reviews`配列が含まれること

### 失敗時の確認ポイント

1. **「みんなのレビューを読み込み中...」が表示されたまま**
   - 原因: APIリクエストが失敗している可能性
   - 確認: Networkタブで`/api/reviews/public`のステータスコードを確認
   - 確認: Consoleタブでエラーメッセージを確認

2. **「公開レビューの取得に失敗しました」が表示される**
   - 原因: APIエラー（500エラーなど）
   - 確認: サーバーのターミナルログを確認
   - 確認: `app/api/reviews/public/route.ts`のエラーハンドリングを確認

3. **「まだ公開レビューがありません」が表示される**
   - 原因: 公開レビュー（`isPublic: true`）が存在しない
   - 確認: データベースで`reviews`テーブルの`is_public = 1`のレコードを確認
   - 確認: レビュー投稿時に`isPublic: true`で投稿されているか確認

4. **コンポーネントが表示されない**
   - 原因: importエラーまたはコンポーネントの配置ミス
   - 確認: `app/books/page.tsx`のimport文を確認
   - 確認: `components/PublicReviewsList.tsx`が存在するか確認
